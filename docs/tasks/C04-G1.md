# C04-G1: approved bundle and device foundation

Goal: Implement the approved G1/G2 contract foundation from ADR-0011: exact
account-bundle transport and compare-and-swap publication, bearer-session device
enrollment, SDK support, and explicit web publication/account-ID discovery.

Dependencies: C04 approval in ADR-0011 (approved 2026-09-05).

Allowed paths: `packages/contracts/`, `docs/contracts/`, `fixtures/contracts/`,
`apps/backend/src/account/`, `apps/backend/src/devices/`,
`apps/backend/src/app.mjs`, `apps/backend/test/`, `db/migrations/`,
`packages/sdk/`, `apps/web/`, `docs/tasks/C04-G1.md`.

Forbidden paths: `crates/crypto-core/`, existing `db/migrations/001_initial.sql`,
crypto-envelope/v1 changes, WebAuthn/recovery-reset, extension sources, and any
plaintext vault/key/password/TOTP fixture or log.

Required implementation:

- Transcribe ADR-0011 G1/G2 into additive machine-readable contract changes
  while preserving previous contract snapshots and generated client compatibility.
- Add bounded, authenticated account key-bundle GET/PUT routes over the existing
  `key_bundles` table. Implement the approved canonical bundle validation,
  initial insert race handling, idempotency, CAS replacement, and distinct
  `KeyBundleConflict` response.
- Add a forward-only migration and routes for G2 bearer-session device enrollment;
  reject rebinding/races; preserve legacy publicKey device behavior.
- Add SDK DTOs/methods and client-side bundle codec with strict field, size,
  canonicalization and wrapper-context validation.
- Add explicit authenticated web publication and copyable account-ID UI. Do not
  generate replacement keys or overwrite a conflicting remote bundle.

Required tests: contract/fixture positives and negatives; account isolation;
missing/malformed/oversized/canonical bundle; initial-write race/CAS/idempotent
retry; legacy and bearer device enrollment; session binding/revoke/refresh;
web-to-server-to-SDK interop; no secret logging.

Verification: package tests, backend integration tests against PostgreSQL,
web build/tests, boundary check, and affected Rust/WASM tests. Report using
`docs/plan/INTEGRATOR.md`.
