# B04: Authentication and devices
Goal: Implement OPAQUE auth, sessions, WebAuthn MFA, device registration/revocation, rate limits, and recovery reset.
Dependencies: B02, A02, H01.
Allowed paths: `apps/backend/src/auth/`, `apps/backend/src/devices/`, `apps/backend/test/auth/`, `db/migrations/` (forward-only B04 migration required by ADR-0005).
Forbidden paths: Crypto-core, client UI, contract changes, and existing migration rewrites.
Inputs and approved contracts: `docs/contracts/api-v1.md`, `docs/contracts/crypto-envelope-v1.md`, `docs/security/RECOVERY.md`.
Required implementation: Session rotation, generic auth errors, revoke propagation, recovery resets revoking sessions/devices, and redacted audit events.
Acceptance criteria: Wrong password never authenticates; revoked devices cannot refresh; server cannot decrypt vault.
Required tests: Registration/login, MFA, replay, rate limit, revoke, recovery, and session rotation E2E tests.
Commands to verify: `bun run --filter @zkpm/backend test -- auth`.
Deliverables: Auth module and security test report.
Risks and escalation conditions: Protocol or recovery changes require H01 re-review.
Completion report format: Standard completion report.
