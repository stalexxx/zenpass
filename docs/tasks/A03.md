# A03: UX flows
Goal: Specify accessible user flows for onboarding, unlock, recovery, vault CRUD, generator, TOTP, import/export, conflicts, revoke, and autofill.
Dependencies: A00.
Allowed paths: `docs/ux/`, `apps/web/src/ux/`.
Forbidden paths: Crypto core, backend, API contracts.
Inputs and approved contracts: `docs/plan/MASTER.md`.
Required implementation: Include loading, error, lock, offline, destructive-action, and recovery-warning states.
Acceptance criteria: Every MVP capability has a testable flow and accessibility acceptance criteria.
Required tests: UX checklist and keyboard/screen-reader review notes.
Commands to verify: `git diff --check`.
Deliverables: UX flow documentation and wireframe-level specifications.
Risks and escalation conditions: Escalate any flow suggesting support can recover plaintext.
Completion report format: Standard completion report.
