# H02: External security audit
Goal: Obtain an external audit of crypto-core, OPAQUE integration, recovery, extension isolation, sync rollback, and supply chain.
Dependencies: Q01.
Allowed paths: `docs/security/`, audit evidence, remediation tests.
Forbidden paths: Silent changes to frozen contracts.
Inputs and approved contracts: Full test report, threat model, ADRs, release candidate.
Required implementation: Track findings to closure and rerun affected tests.
Acceptance criteria: No unresolved Critical/High findings; accepted residual risk is documented by a human.
Required tests: Auditor-selected tests plus regression suite.
Commands to verify: `bun run test:security`.
Deliverables: Audit report, remediation log, human sign-off.
Risks and escalation conditions: Any protocol finding blocks release.
Completion report format: Standard completion report.
