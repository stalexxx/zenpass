# R01: Personal MVP release
Goal: Deploy and operate the audited personal MVP through staged rollout.
Dependencies: H02.
Allowed paths: `infra/`, `docs/runbooks/`, release configuration, changelog.
Forbidden paths: Crypto protocol and application behavior unless a new task is opened.
Inputs and approved contracts: All merged components, audit report, deployment and backup runbooks.
Required implementation: EU staging/production, migrations, observability without user content, incident and deletion procedures, staged rollout.
Acceptance criteria: Restore drill passes; rollout can be halted; release checklist signed.
Required tests: Staging smoke, migration, backup restore, rollback, account deletion, device revoke.
Commands to verify: `bun run test:release`; `terraform plan`.
Deliverables: Release artifact, signed checklist, operational dashboard links.
Risks and escalation conditions: Stop release for unresolved Critical/High security findings.
Completion report format: Standard completion report.
