# B05: Sync backend
Goal: Implement opaque item mutations, revisions, tombstones, cursors, conflicts, and idempotency.
Dependencies: B02, B04, A02.
Allowed paths: `apps/api/src/sync/`, `apps/api/test/sync/`, `db/migrations/`.
Forbidden paths: Decryption code, client UI, crypto contract.
Inputs and approved contracts: `docs/contracts/sync-v1.md`, `docs/contracts/api-v1.md`.
Required implementation: `baseRevision`, `mutationId`, monotonic change sequence, 409 conflict payload, replay-safe cursor feed, and retention.
Acceptance criteria: Server never merges ciphertext and two concurrent writes are both recoverable.
Required tests: Conflict, replay, pagination, tombstone, rollback, and multi-device tests.
Commands to verify: `bun run --filter @zkpm/backend test -- sync`.
Deliverables: Sync module, migration, contract test results.
Risks and escalation conditions: Escalate any temptation to inspect ciphertext.
Completion report format: Standard completion report.
