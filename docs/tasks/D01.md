# D01: Desktop client
Goal: Add Tauri desktop clients using the stable Rust core and native messaging.
Dependencies: R01.
Allowed paths: `apps/desktop/`, `crates/crypto-ffi/`, desktop packaging configuration.
Forbidden paths: Envelope/sync contracts without ADR.
Inputs and approved contracts: Stable crypto-envelope, sync, SDK, and native messaging design.
Required implementation: Windows/macOS/Linux packaging, OS keychain wrapped material, biometric unlock, extension native messaging.
Acceptance criteria: Desktop passes the same vectors and sync E2E as web.
Required tests: Platform smoke, keychain, lock, native messaging, and sync tests.
Commands to verify: `bun run --filter desktop test`; platform packaging checks.
Deliverables: Signed desktop artifacts and platform matrix.
Risks and escalation conditions: Escalate platform keychain differences.
Completion report format: Standard completion report.
