# B03: WASM and native bindings
Goal: Expose the Rust crypto-core to TypeScript/WASM and future native clients through a Worker-safe adapter.
Dependencies: B01.
Allowed paths: `packages/crypto-wasm/`, `packages/crypto-worker/`, `crates/crypto-ffi/`.
Forbidden paths: Backend and UI business logic.
Inputs and approved contracts: `docs/contracts/crypto-envelope-v1.md`.
Required implementation: Generated TypeScript declarations, Worker message protocol, UniFFI smoke bindings, and secret-lifetime rules.
Acceptance criteria: Native and WASM pass identical golden vectors; UI cannot access raw keys directly.
Required tests: Binding, vector, malformed-message, and Worker lifecycle tests.
Commands to verify: `pnpm test --filter crypto-wasm`; `cargo test -p crypto-ffi`.
Deliverables: Published local packages and usage docs.
Risks and escalation conditions: Escalate memory ownership or serialization mismatch.
Completion report format: Standard completion report.
