# H01: Human security approval
Goal: Approve the threat model, crypto specification, libraries, recovery semantics, and vectors before implementation.
Dependencies: A04.
Allowed paths: `docs/security/`, `docs/decisions/`.
Forbidden paths: Production code and unreviewed protocol changes.
Inputs and approved contracts: A01, A04, crypto vectors, dependency licenses.
Required implementation: Record explicit approval or findings; Critical/High findings return A04 to READY.
Acceptance criteria: Human reviewer signs the decision and freezes `crypto-envelope/v1`.
Required tests: Independent vector verification and security checklist.
Commands to verify: `git diff --check`.
Deliverables: Signed review record/ADR.
Risks and escalation conditions: No crypto implementation may merge without approval.
Completion report format: Standard completion report.
