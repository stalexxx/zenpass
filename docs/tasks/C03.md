# C03: Browser extensions
Goal: Implement Chrome and Firefox extensions for save/update prompts, secure autofill, TOTP, and locking.
Dependencies: C01, C02.
Allowed paths: `apps/extension/`, `packages/extension-adapters/`.
Forbidden paths: Backend, crypto primitives, contract edits.
Inputs and approved contracts: UX flows, SDK, origin-matching rules, WebExtensions platform constraints.
Required implementation: Background service worker session, popup, content-script minimal data flow, separate manifests, minimal permissions, no remote code.
Acceptance criteria: Never autofill HTTP, look-alike, ambiguous, or untrusted cross-origin forms.
Required tests: Chromium/Firefox E2E on forms, SPA navigation, iframe, subdomain, hostile-domain, save/update, TOTP, and lock flows.
Commands to verify: `pnpm test --filter extension`; `pnpm build --filter extension`.
Deliverables: Two store-ready packages and permission review.
Risks and escalation conditions: Escalate browser incompatibility rather than weakening origin checks.
Completion report format: Standard completion report.
