# B02: Backend foundation
Goal: Bootstrap Fastify API, PostgreSQL schema/migrations, config, logging, health endpoints, local containers, and Terraform skeleton.
Dependencies: A02.
Allowed paths: `apps/api/`, `infra/`, `db/`.
Forbidden paths: Crypto implementation, client UI, contract edits.
Inputs and approved contracts: `docs/contracts/api-v1.md`.
Required implementation: Structured redacted logs, readiness/liveness, migration runner, env validation, EU deployment configuration.
Acceptance criteria: API starts locally, migrations are repeatable, and logs contain no request bodies/secrets.
Required tests: Migration, health, logging-redaction tests.
Commands to verify: `pnpm test --filter api`; `pnpm lint --filter api`.
Deliverables: Foundation service and local compose environment.
Risks and escalation conditions: Escalate any schema field that could store plaintext vault data.
Completion report format: Standard completion report.
