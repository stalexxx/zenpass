# A00: Repository foundation
Goal: Bootstrap the monorepo, package boundaries, Rust workspace, CI, CODEOWNERS, and dependency policy.
Dependencies: None.
Allowed paths: Root build/config files; `apps/`; `packages/`; `crates/`; `.github/`; `CODEOWNERS`.
Forbidden paths: Product implementation, frozen contracts, security decisions.
Inputs and approved contracts: `docs/plan/MASTER.md`.
Required implementation: Empty buildable web, extension, backend, SDK, and Rust core placeholders; lint/test/build CI; lockfile policy.
Acceptance criteria: Clean checkout builds and tests with one documented command.
Required tests: CI smoke build and package-boundary check.
Commands to verify: `bun install --frozen-lockfile`; `bun run test`; `bun run build`.
Deliverables: Commits prefixed `A00`, setup notes, changed-path report.
Risks and escalation conditions: Ask integrator before adding a dependency or changing package boundaries.
Completion report format: Task, Status, Commits, Changed paths, Verification commands/results, Limitations, Security considerations, Follow-up tasks.
