# D02: Mobile clients
Goal: Add React Native iOS/Android clients using UniFFI and platform secure storage/autofill.
Dependencies: R01.
Allowed paths: `apps/mobile/`, `crates/crypto-ffi/`, mobile build configuration.
Forbidden paths: Envelope/sync contracts without ADR.
Inputs and approved contracts: Stable crypto-envelope, sync, SDK, UX flows.
Required implementation: Keychain/Secure Enclave, Android Keystore, biometric unlock, iOS Password AutoFill, Android Autofill Framework.
Acceptance criteria: Mobile vectors, lock lifecycle, recovery, and sync pass on supported OS versions.
Required tests: Native binding, secure storage, biometric, autofill, offline, and sync tests.
Commands to verify: `bun run --filter mobile test`; platform build checks.
Deliverables: Mobile proof-of-concept and compatibility matrix.
Risks and escalation conditions: Escalate platform API limitations; never downgrade key protection silently.
Completion report format: Standard completion report.
