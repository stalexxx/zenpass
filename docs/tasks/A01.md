# A01: Threat model
Goal: Produce the asset, trust-boundary, threat, mitigation, and verification model.
Dependencies: A00.
Allowed paths: `docs/security/THREAT-MODEL.md`, `docs/security/DECISIONS.md`.
Forbidden paths: Code, contracts, crypto implementation.
Inputs and approved contracts: `docs/plan/MASTER.md`.
Required implementation: Cover server/database theft, malicious API, XSS, extension abuse, device theft, brute force, supply chain, phishing, rollback, and metadata leakage.
Acceptance criteria: Every threat maps to a mitigation and test; irrecoverable password/recovery loss is explicit.
Required tests: Review checklist, no automated code test required.
Commands to verify: `git diff --check`.
Deliverables: Threat model and open questions.
Risks and escalation conditions: Escalate any requirement that weakens zero-knowledge.
Completion report format: Standard completion report.
