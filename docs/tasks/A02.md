# A02: Domain, API, and sync contracts
Goal: Define versioned domain types, OpenAPI `/v1`, JSON schemas, sync state machine, fixtures, and negative examples.
Dependencies: A00.
Allowed paths: `docs/contracts/api-v1.md`, `docs/contracts/sync-v1.md`, `packages/contracts/`, `fixtures/contracts/`.
Forbidden paths: Backend handlers, client UI, crypto algorithms.
Inputs and approved contracts: `docs/plan/MASTER.md`.
Required implementation: Specify account/device/vault/item/revision/cursor/tombstone/mutation and all endpoint request/response/error shapes.
Acceptance criteria: Generated schema validates every fixture; conflict, idempotency, and cursor semantics are unambiguous.
Required tests: Schema validation and contract fixture tests.
Commands to verify: `pnpm test --filter contracts`.
Deliverables: Frozen `api/v1` and `sync/v1` contracts.
Risks and escalation conditions: Contract changes after consumers start require an ADR.
Completion report format: Standard completion report.
