# C02: Shared TypeScript SDK
Goal: Generate API client and implement sync state machine, encrypted local repository interface, import normalizers, and origin matching.
Dependencies: A02, B03, B05.
Allowed paths: `packages/sdk/`, `packages/importers/`, `packages/domain/`, plus `packages/crypto-wasm/` (ADR-0007: adding client-side OPAQUE exports only — mechanical wrapping of existing `crypto_core::opaque` client functions, no new cryptography, no change to B03's existing envelope/session exports).
Forbidden paths: AEAD/KDF implementation, DOM code, backend handlers, `crates/crypto-core`.
Inputs and approved contracts: OpenAPI and sync contracts; crypto WASM bindings.
Required implementation: Offline queue, cursor persistence, idempotent mutation handling, conflict objects, Enpass/1Password/Bitwarden/CSV normalizers.
Acceptance criteria: SDK handles offline/reconnect/conflict simulation without plaintext persistence.
Required tests: Contract, offline, import, origin-matching, and serialization tests.
Commands to verify: `bun run --filter @zkpm/sdk test`.
Deliverables: SDK packages and generated API types.
Risks and escalation conditions: Escalate any need for crypto outside Rust bindings.
Completion report format: Standard completion report.
